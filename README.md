# 黑夜君臨 戰技尋獲表 / Nightreign Skill Finder

《艾爾登法環 黑夜君臨》（ELDEN RING NIGHTREIGN）的戰技查詢工具。選一個戰技，頁面會列出最容易取得它的地點，以及在那裡該找哪一種武器。介面支援繁體中文、日文、英文。

## 功能

- **推薦地點**：依「擊敗頭目後，獎勵選項中至少出現一把帶此戰技的武器」的機率排序，涵蓋一般地圖與大空洞（DLC）的據點頭目、野外頭目、城、封印監牢等。
- **武器種分析**：在選定地點，各武器種掉落時是這個戰技的條件機率，以及占比。
- **個別武器偏差**：部分武器有自己的戰技表或固定戰技（例如蟻刺細劍），這些會逐把列出，不用武器種平均估算。
- **易發現的武器種**：可選角色預設，或在深夜模式指定武器種。「職業武器」獎勵欄位的抽選會跟著改變。

## 計算方式

- 據點的屬性決定武器的屬性。例如雷屬性遺跡的頭目約 75% 抽雷屬性武器表、25% 抽普通屬性表。
- 戰技從「該武器 × 該屬性」的戰技表等權重抽出，所以戰技池越小的武器種，抽中特定戰技的機率越高。
- 頭目的每一列掉落視為一個獎勵選項：至少出現一次 = 1 − Π(1 − 各選項機率)。
- 寶箱與一般敵人的掉落未列入。

資料版本：遊戲本體資料 2026-04-01 版。遊戲改版後機率可能會變動。

## 檔案

- `index.html`：網頁本體，所有資料都內嵌在檔案裡，不需要伺服器。
- `build/template.html`：頁面樣板（樣式與程式）。
- `build/build.py`：把抽取好的遊戲資料嵌入樣板，產生 `index.html`。抽取遊戲資料的步驟不包含在此 repo 中。

## 使用 GitHub Pages

在 repo 的 **Settings → Pages** 選擇 `main` 分支、根目錄（`/`），儲存後即可透過 `https://<帳號>.github.io/<repo>/` 開啟。
